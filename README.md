# FoodSave

FoodSave is a responsive, front-end prototype for a sustainable food-rescue marketplace. It uses fictional restaurant partners, locations, availability and impact statistics for demonstration. Checkout and partner forms are local-only; no real payment or submission is made.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. To create a production build, run `npm run build`; to preview it, run `npm run preview`.

## Prototype notes

- The cart is saved in the browser's local storage.
- The nearby map is an illustrative Dubai map, not a live map or location service.
- Food photography and display fonts load from Unsplash and Google Fonts.
- All AED pricing, restaurant details, pickup times, availability and impact metrics are demo content.
- FoodSave's planned 20% allocation applies to company profit, not total sales.
